VisionBrain

the instrument · local-first product

Aerial & camera vision AI running entirely on one Mac. Three MLX models stitched into a single pipeline — Falcon Perception grounds plain language, SAM 3.1 tracks with pixel masks, Gemma 4 26B reasons about what it sees. A Ground Control web UI, a live field hub, and a CLI wrap all of it into something an operator runs offline. Weights live in your Hugging Face cache; results live on your disk.

supervision

the toolbox · open-source library by roboflow

"We write your reusable computer vision tools." The model-agnostic plumbing behind modern cv apps: one detections container — sv.Detections — that ~17 model converters feed into, with tracking, annotators, zones, small-object slicing, dataset i/o, and benchmark metrics on the other side. MIT-licensed, ~50k stars, and the hub of an ecosystem: RF-DETR, the trackers package, and roboflow inference all speak its container natively.

nature

An end-to-end product: opinionated pipeline, ui, and storage decisions already made. You operate it.

posture

A library: reusable parts with almost no opinions. You assemble it — model, ui, and deployment are yours to bring.

models

Ships three: falcon perception, sam 3.1 (mlx-community/sam3.1-bf16), gemma 4 26b — plus lfm variants. All MLX-optimized, resolved from the local cache.

ai brains

Ships none. Model-agnostic by design — bring any detector; rf-detr returns sv.Detections natively. It parses vlm text, it doesn't run models.

tracking

A dependency-free canonical tracker (persistent ids, occlusion states, stale-frame prediction) built for the live hub — with the supervision byte-track available on the video path behind a version-proof wrapper.

identity

Built-in sv.ByteTrack is deprecated (removed in 0.31.0). The successor is the trackers package: six algorithms, hota 58→64, one update(detections) api.

masks

Sam 3.1 dense masks, converted to normalized polygons and painted live in the dashboard — boxes as fallback, all inside the jpeg wire frame.

◆

CompactMask — rle-cropped masks, 10–240× less memory, coco rle in with zero dense allocation. Built for scale, not for a live feed.

zones & events

Line-cross, zone-enter/exit, dwell, and 8-way compass direction — computed per frame and emitted as wire events the dashboard and reports consume.

geofencing

LineZone / PolygonZone primitives with in/out counts — capable, but you write the loop that turns them into events.

reasoning

Gemma 4 asks and answers. "What changed since last pass?" — grounded in the observation, resolved over ollama / remote gpu / local mlx, delivered as field reports.

thinking

None. It moves detection data; it never interprets it. The closest move is parsing nine vlm text formats into boxes.

interface

Three surfaces, included: ground control web ui, cli (10 verbs), and the ws field hub — record mp4/webm client-side with overlays baked in.

surface

One surface: the Python api. Docs, cookbooks, and an annotator playground — but every ui is yours to build.

validation

Cross-engine validation and a counts line you can read over the radio. Honest status verbs: ready · cached · missing.

qa

The full bench: mAP · mar · f1 · confusion matrix with small/medium/large buckets, plus per-image error mosaics. Rigor we don't ship.

where it runs

One Mac mini m4, offline. No subscription, no sync, no telemetry. Field-bridge modules import with zero mlx installed.

hardware

Anywhere python ≥3.10 runs; opencv optional since 0.30. Hardware-agnostic — and ui-less until you add a screen.

community

One operator-engineer. The docs are the spec; the spec is the memory. Changes land when the field needs them.

scale

Thousands of contributors, 1m+ downloads a month, 2026 release cadence re-accelerated (0.28 → 0.30.2 in four months), docs published as llms.txt for machine readers.

simple to operate

Install once, check the cache, launch. Three commands from nothing to a live dashboard — the opinions are the simplicity.

$ pip install -e .
$ python -m visionbrain status   # what's cached?
$ python -m visionbrain track drone.mp4 \
    --query "person, vehicle" --persistent-ids
$ python -m visionbrain ui        # ground control

Six lines from any model to an annotated, tracked frame. Nothing decided for you — nothing in your way either.

shared dna — why this is a comparison, not a fight
◇sv.Detections contract ◇byte-track lineage ◇line + polygon zones ◇annotators ◇compact masks ◇visionbrain pins supervision ≥0.28,<0.30 ◇bridge: visionbrain → sv.detections

Supervision is the wrench set. VisionBrain is the machine that arrives in the field with the wrenches already mounted.

They are not competitors — one imports the other. VisionBrain converts its model outputs to sv.Detections and reuses supervision's tracker, zones, and annotators where they fit, while the canonical tracker, wire protocol, and reasoning chain stay in-house. When supervision 0.31 removes its byte track, the swap to the trackers package is one wrapper away.
