VisionBrain · design study 005 · integration plan · 2026-09-08

Absorb the toolbox. Keep the instrument.

How every benefit found in the roboflow/supervision recon lands in VisionBrain — maximum capability, zero new concepts for the operator. The recon (SUPERVISION_RECON.md) mapped what upstream does well. This page is the plan for pulling it in: nine integrations, three phases, one rule — every capability arrives behind a surface that already exists.

▷one query box

Capability lands behind routing, not behind new ui. The operator keeps typing plain language; the pipeline quietly gets deeper underneath.

▷flags, not concepts

Power shows up as a flag or toggle an operator can ignore forever. Defaults are opinionated and correct; experts get the dial.

▷same shapes out

Whatever we adopt upstream, results leave through the same four doors: the dashboard canvas, json, mp4/webm, and a gemma report.

01
identity

The trackers package

Swap the bridge wrapper's internals to ByteTrackTracker from pip install trackers — near drop-in (update() rename). Unlocks six algorithms behind one api.

the operator gets

Steadier ids through occlusion, and a choice of trackers per mission — sort for speed, bot-sort for quality — without touching code.

stays invisible

ships as --tracker bytetrack|sort|oc-sort|bot-sort
default unchanged; wrapper absorbs the rename · new flag

02
memory

Compact masks end to end

Drop the hand-built side-cache. Build detections with the upstream mask=CompactMask field, and ingest falcon's coco rle directly via CompactMask.from_coco_rle — no dense (n,h,w) allocation, ever.

the operator gets

Longer tracks and longer lives streams on 16 gb — 10–240× less mask memory, so hour-long missions stop flirting with swap.

stays invisible

internal to supervision_bridge; polygons on the wire unchanged. delete ~70 lines of cache code · no surface change

03
foundation

The 0.31 move

When supervision 0.31.0 ships (in dev now), move the pin from >=0.28,<0.30 to >=0.31,<0.33 + trackers≥2. Upstream promises a 3-minor deprecation window — that's the planning clock.

the operator gets

Nothing visible — by design. The point of a foundation phase: behavior stays put while the floor under it gets current.

stays invisible

one pin change + regression pass over TestSupervisionBridge; opencv-optional is irrelevant (we render numpy/pil) · maintenance

04
capability

Inference slicer for aerial frames

Wire the InferenceSlicer into the falcon detect path: split a 4k drone still into overlapping tiles, detect per tile, merge with nms. Small-object sahi, upstream-maintained.

the operator gets

Finds the three-person crew on a full-width wing — objects that vanish at full-frame scale. The aerial case, finally first-class.

stays invisible

ships as detect --slice 1280 and auto-on for images ≥4k in auto mode · new flag + routing

05
capability · flagship

Gemma-grounded boxes

Prompt gemma to answer in a vlm text format, parse with sv.Detections.from_vlm — boxes with labels straight out of the reasoning model, when falcon has no route for the phrase.

the operator gets

"How many red trucks?" gets a real answer with real boxes — open-vocabulary queries beyond falcon's vocabulary, no new model to install.

stays invisible

lands inside the existing auto route (prompt_router) and the live ask button; falls back gracefully · spike first

06
trust

Real metrics: visionbrain eval

Adopt MeanAveragePrecision / F1Score / ConfusionMatrix (size buckets, masks target) behind a new eval verb — score our engines against a labeled folder, plus the upstream error mosaics.

the operator gets

A report card for their own footage — "falcon: 0.71 map50 on my site, weak on small objects" instead of vibes.

stays invisible

ships as visionbrain eval --dataset yolo/ --engine falcon; output lands in the reports pipeline · new verb

07
workflow

Dataset round-trip

Load labeled sets with DetectionDataset.from_yolo/from_coco for eval; export interesting tracks with as_yolo — the labeling loop, closed.

the operator gets

fastscan finds the six interesting minutes; export hands them to a labeling tool — footage in, training data out, still one machine.

stays invisible

ships as track --export-yolo out/ and eval --dataset above · new flags

08
polish

Annotators + smoother on the dashboard

Adopt DetectionsSmoother to steady jittery sam boxes, and expand overlays from the current four annotators (trace · halo · heatmap · rich labels are upstream anyway).

the operator gets

A feed that looks calmer than the model is — smoothed boxes, motion trails, and a heatmap toggle for "where has everything been."

stays invisible

dashboard display toggles extend the existing boxes/masks pair; off by default · ui toggles

09
interop

Sinks & zone upgrades

Track output gains CSVSink-style columns; zones adopt upstream fixes we currently lack — per-class line counts and require_all_anchors=False triggers.

the operator gets

Counts that open in a spreadsheet, per class — and zone lines that trigger when any part of the object crosses, not just one anchor.

stays invisible

extends the existing json track output + zones.py counters; wire format backward-compatible · small

the ease contract — one query, whole stack
  1. operator"count vehicles crossing the north line in sunrise.mp4 and flag anything unusual" — typed once, in plain language.
  2. prompt routerroutes to sam 3.1 tracking, flags "north line" as a zone spec, arms vehicle classes. no prompts field, no config.
  3. bridge + trackersdetections become sv.detections; the chosen tracker holds identity across occlusions — compact masks keep memory flat for the full flight.
  4. zoneslinezone emits per-class crossing events; the smoother steadies boxes; polygon triggers watch the apron on the side.
  5. gemma "14 vehicles crossed northbound between 06:12 and 06:31; one stopped inside the zone for 4 minutes — flagged." the report lands on the same paper surface it always has.
  6. out mp4 with overlays, csv of crossings, json events, gemma report — the four doors, same as day one.

Every upstream capability we adopt makes the pipeline deeper — never the operator's day harder.

Sequencing note: phase 1 is deliberately unglamorous. The 0.31 upgrade and the trackers swap are the load-bearing moves; the flagship gemma-grounding spike (05) only starts once the floor is current, so we never build a new capability on a pinned, aging bridge.
