The CLI dispatch table calls the cli.py:667 definition. The copy at frame_selector.py:385 is never invoked — classic trap for future edits landing in the wrong function. Remove ~lines 380–427 (keep score_frames(); that part is used).

P3

Resolve the implementation-notes filename collision

IMPLEMENTATION_NOTES.md (Tier 2 run-state feedback, 2 KB) and implementation-notes.md (Options A+B pipeline, 8.8 KB) differ only by letter case. Git tracks both, but default macOS/Windows filesystems are case-insensitive — cloning there makes them collide and clobber each other. Rename the lowercase one, e.g. IMPLEMENTATION_NOTES_FAST_PIPELINE.md, or fold its content into FAST_PIPELINE_SPEC.md. AGENTS.md references the glob IMPLEMENTATION_NOTES*.md, so any kept name stays valid.

git mv implementation-notes.md IMPLEMENTATION_NOTES_FAST_PIPELINE.md

P5

Sweep cache junk (optional — already gitignored)
